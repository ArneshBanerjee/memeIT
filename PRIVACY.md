# Privacy

MemeIT 0.1.0 performs library search locally. It does not require an account and does not collect telemetry. It does not read your conversations or clipboard history. Copying a selected meme replaces the clipboard only after you request it.

Imported images and GIFs, their titles/descriptions/tags, favorites, and recent-copy timestamps are stored in the app's per-user data directory. The app does not upload them. Uninstalling the application may leave this data behind; remove its data directory if you want to erase the library.

The desktop application includes its starter media and does not need an online meme provider. The download website contacts GitHub to obtain release metadata. Hosting and download providers receive ordinary web request information under their own privacy policies.

Any future online catalog or model download must explain the destination, data transferred, and storage behavior before activation. The public website is not a proxy for private searches.
