# Changelog

## 0.1.2 — Copy now, keep it for later

- Copy captioned memes directly to the clipboard and automatically keep them in Your memes, with content-based deduplication.
- Reuse creations, import personal images/GIFs, and optionally rename or describe them.
- Extend local semantic retrieval to saved and imported descriptions.
- Expand verified contemporary formats, including 6–7, and test visual descriptions without meme names.
- Persist browser-preview creations locally and preserve clipboard user activation.

## 0.1.1 — Natural-language retrieval

- Added local sentence embeddings for meaning-based desktop search, combined with typo-tolerant names and descriptions.
- Added verified internet reactions omitted by popular feeds, including Cooked Dog.
- Improved browser-preview matching for word forms, swapped letters, and full visual descriptions.


## 0.1.0 — Initial preview

- Rust/Tauri desktop picker for real popular internet meme formats from live Imgflip and Memegen catalogs.
- Description metadata and intent search, plus optional credentialed KLIPY GIF/meme and full Imgflip search.
- On-device template caption editor with movable text layers, styling, PNG copy, and save.
- Native image copying/saving, original local GIF file copying, and provider-aware link sharing.
- Local imports, editable descriptions, favorites, recents, global shortcut, tray, and single instance.
- Windows, macOS, and Linux release workflow and Vercel download website.
- Broad provider access requires credentials; general embedding search and trusted installer signing remain follow-up work.
