Catalog access, early builds & compatibility

Catalog access. The default catalog covers popular Imgflip and Memegen image formats, plus verified internet reactions. Desktop search matches descriptions and meaning with a bundled local language model; no AI key is needed. It isn’t every meme on the internet. Broader KLIPY GIF/meme search needs an API key and production approval; it is not preconfigured. Imgflip’s full database search needs a separate paid API key. Provider searches need an internet connection and follow each provider’s terms.

Add your text. Caption static Imgflip and Memegen templates locally, then copy straight to the clipboard. Your creation is automatically kept in Your memes for next time. Exports fit within 1,600 pixels on the longest side. Bring your own images or GIFs with Import memes and optionally name or describe them. No captioning account or API key is needed for popular templates.

Your data. Online providers receive the searches and media requests you make to them. Imported files stay on your device. MemeIT does not read or send your chats.

Early builds. Early builds are previews. macOS builds use ad-hoc signing unless a release explicitly says they are notarized. Windows builds may be unsigned. Your operating system may display a warning or block an untrusted app; see the release notes before installing.

KLIPY currently copies a provider link; direct GIF-file sharing is pending provider approval. Imgflip/Memegen images and your imported files can be copied as media. File paste depends on the receiving app; save and attach permitted files if needed. Linux builds target modern distributions with WebKitGTK 4.1; global shortcuts and clipboard behavior vary on Wayland. Mobile versions are not included.
