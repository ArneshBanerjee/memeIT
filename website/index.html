A quick note on early builds & compatibility

Early builds are previews. macOS builds use ad-hoc signing unless a release explicitly says they are notarized. Windows builds may be unsigned. Your operating system may display a warning or block an untrusted app; see the release notes before installing.

GIF file paste depends on the receiving app. If your chat doesn’t accept it, save the file and attach it. Linux builds target modern distributions with WebKitGTK 4.1; global shortcuts and clipboard behavior vary on Wayland. Mobile versions are not included.
