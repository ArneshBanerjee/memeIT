# MemeIT assets

The application starts with live internet catalogs, not a bundled custom meme collection. `internet-metadata.json` adds search descriptions for recognized internet formats; media remains with its credited source. `catalog.json` is empty and retained for the local-library seed schema.

`icon.png` is the original MemeIT application icon, released under CC0 in LICENSE. Third-party meme imagery is not covered by that license.
